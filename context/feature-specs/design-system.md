# Objective

We are adding design system to the project by following NuxtUI 4 best practices and using Tailwind CSS 4 for styling, please read `ui-context.md` for UI context guideline, and app only uses dark theme.

Note: NuxtUI and tailwindcss are already installed, so you don't need to install them, just configure them properly.

## Instructions

- Use nuxt-ui MCP for up-to-date information about nuxt ui.
- Use nuxt-ui skill to get the detailed instructions on how to configure nuxt ui.
- Use context7 MCP to read latest documentation about nuxt ui/tailwindcss.

## Check when done

- Only dark theme.
- Use Black color as application background color.
- Use brand color as primary color.
- Default border-radius is 0.375rem.
- Font family is setup as we defined.
- Never use raw Tailwind palette colors in components, templates or class names, always use semantic colors.
