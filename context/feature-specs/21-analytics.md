# Objective

Add an analytics to the website that can track page views and custom events etc.

# Implementations

Help me add Vercel Web Analytics to this project. First, make sure the Vercel CLI is installed (`pnpm i -g vercel`). If I'm using Claude Code or Cursor, install the Vercel Plugin (`pnpx plugins add vercel/vercel-plugin`). For other agents, install Vercel Skills (`pnpx skills add vercel-labs/agent-skills`). Then:

## Step 1 - Install @vercel/analytics.
## Step 2 - Add the Analytics component to my root layout.
## Step 3 - Deploy with `vercel --prod` and verify analytics data appears in the Vercel dashboard.
